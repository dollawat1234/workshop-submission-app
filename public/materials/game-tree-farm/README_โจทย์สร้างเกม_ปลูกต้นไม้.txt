===================================================================
🌳 AI WORKSHOP: ภารกิจสร้างเกมปลูกต้นไม้ เก็บแอปเปิ้ล แลกเหรียญทอง
===================================================================

[บริบทของเกม]
ผู้เข้าร่วมเวิร์กชอปจะได้ใช้ AI (เช่น Claude 3.5 Sonnet / ChatGPT 4o / Cursor) 
ในการเขียนเกม HTML5/JavaScript จำลองการทำฟาร์มปลูกต้นไม้น่ารักๆ

[ไฟล์ Sprite Assets ที่มีให้]
1. tree_stage1_seedling.png - ต้นกล้าเล็ก
2. tree_stage2_growing.png  - ต้นไม้เริ่มโต
3. tree_stage3_mature.png   - ต้นไม้ใหญ่พร้อมออกผล
4. apple_fruit.png          - แอปเปิ้ลแดง
5. golden_apple.png         - แอปเปิ้ลทองคำ (แรร์ไอเทม 10x คะแนน)
6. gold_coin.png            - เหรียญทองคำ
7. game_starter_prompt_and_code.html - โค้ด HTML ตั้งต้น

[เป้าหมายของ Workshop]
1. สั่ง AI เขียนระบบ Level & Growth: กดรดน้ำต้นไม้แล้วค่อยๆ โตจาก Stage 1 -> 2 -> 3
2. เมื่อโตเต็มที่ ต้นไม้จะดรอปแอปเปิ้ล มีโอกาส 10% ดรอปแอปเปิ้ลทองคำ
3. มีระบบร้านค้า (Marketplace) นำแอปเปิ้ลไปขายเป็นทอง และใช้ทองซื้อปุ๋ยเร่งโต
4. มีเสียง Effect หรือ Confetti เวลาอัปเกรดสำเร็จ

[ตัวอย่าง Prompt สำหรับให้ AI เขียนโค้ดเกมให้สมบูรณ์]
"ฉันมีไฟล์รูป assets เกมปลูกต้นไม้ (tree_stage1, tree_stage2, tree_stage3, apple_fruit, gold_coin) 
ช่วยเขียนเกม HTML + Tailwind CSS + Vanilla JS แบบ Single File ที่มีฟีเจอร์:
 1. กดปุ่มรดน้ำเพื่อสะสม Growth EXP เมื่อครบ 100% ต้นไม้จะเปลี่ยนภาพเป็นต้นใหญ่
 2. เมื่อต้นใหญ่ กดเก็บแอปเปิ้ลได้ครั้งละ 3-5 ผล (สุ่มแอปเปิ้ลทองคำได้ทอง 50 เหรียญ)
 3. ร้านค้าอัปเกรด: ซื้อสปริงเกลอร์รดน้ำอัตโนมัติ และปุ๋ยทองคำ
 4. มี Animation เด้งดุ๊กดิ๊ก และบันทึกคะแนนลง localStorage"
