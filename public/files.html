โจทย์ 1 · EXCEL & DATA ANALYSIS

ตามหาลูกค้าประจำร้านไอศกรีม

รวมยอดขาย 3 สาขา แล้วใช้ข้อมูลจริงตอบให้ได้ว่าใคร “มาซื้อบ่อยที่สุด” และใคร “มียอดซื้อรวมสูงที่สุด”

คำสั่งโจทย์
  1. รวมไฟล์ยอดขายจากสาขาสยาม ริเวอร์ไซด์ และทองหล่อ แล้วเชื่อมกับทะเบียนลูกค้ากลาง
  2. นับใบเสร็จไม่ซ้ำ โดยตัดรายการยกเลิกออก และรวมหลายบรรทัดในใบเสร็จเดียวก่อนนับ
  3. ระบุลูกค้าประจำหลายสาขา (อย่างน้อย 3 ใบเสร็จ, 3 วัน และ 2 สาขา) พร้อมหลักฐานที่ตรวจย้อนกลับได้
  4. สรุป 2 อันดับแยกกัน: บิ๊กเบน = ซื้อบ่อยที่สุด และ ไอเฟล = ยอดซื้อรวมสูงที่สุด
ผลงานที่ต้องส่งExcel .xlsxมีชีตข้อมูลรวม + ชีตสรุปผลวิเคราะห์

RULES: นับเฉพาะ DocumentType = “ขาย” และ Status = “สำเร็จ”; รวมหลายบรรทัดเป็นใบเสร็จเดียวก่อนนับ; ลูกค้าประจำหลายสาขาต้องมีอย่างน้อย [เกณฑ์ลูกค้าประจำ] และรายงานเลขที่ใบเสร็จ/วันที่/สาขาเป็นหลักฐาน

OUTPUT: ทำชีตสรุป 3 ส่วน ได้แก่ (1) ลูกค้าประจำหลายสาขา (2) ผู้ซื้อบ่อยที่สุด ซึ่งคำตอบที่ต้องตรวจให้พบคือ [ชื่อลูกค้าซื้อบ่อย] (3) ผู้มียอดซื้อสุทธิรวมสูงที่สุด ซึ่งคำตอบที่ต้องตรวจให้พบคือ [ชื่อลูกค้ายอดสูง] พร้อมวิธีตรวจความถูกต้องและรายการจับคู่ไม่ได้ ห้ามเดาข้อมูล

โจทย์ 2 · DATA CLEANSING

ล้างข้อมูลลูกค้าร้านอาหารสัตว์

ข้อมูลดิบไฟล์เดียว แต่ชื่อและเบอร์โทรมีหลายรูปแบบ ให้เปลี่ยนความยุ่งเหยิงเป็นตารางที่เชื่อถือได้

คำสั่งโจทย์
  1. ตรวจหาและจัดกลุ่มชื่อคนเดียวกันที่สะกดต่างกัน เช่น ภาษาไทย ภาษาอังกฤษ ขีดคั่น และช่องว่างเกิน
  2. ทำมาตรฐานเบอร์โทรให้เป็นรูปแบบเดียวกัน โดยเก็บเลข 10 หลักที่ตรวจสอบได้
  3. ตัดช่องว่างหัว–ท้าย ปรับตัวพิมพ์ และระบุแถวซ้ำโดยไม่ลบข้อมูลต้นทาง
  4. ส่งออกตารางสะอาดที่มีคอลัมน์คีย์ลูกค้าเดียว พร้อมบันทึกว่าแต่ละแถวถูกแก้ไขอย่างไร
ผลงานที่ต้องส่งExcel .xlsxเก็บชีต Raw เดิม + Cleaned Data ที่พร้อมวิเคราะห์

RULES: รวมชื่อที่เป็นคนเดียวกันโดยใช้เบอร์โทรเป็นหลัก; แปลงเบอร์โทรเป็น [รูปแบบเบอร์โทร]; trim ช่องว่าง; ปรับตัวพิมพ์ภาษาอังกฤษ; ทำเครื่องหมาย duplicate แต่ห้ามลบ Raw Data; สร้างคอลัมน์ [คอลัมน์คีย์ลูกค้า] เป็นชื่อมาตรฐาน

OUTPUT: ส่งไฟล์ Excel ที่มี Raw Data, Cleaned Data และ Change Log ระบุค่าเดิม/ค่าใหม่/เหตุผลในแต่ละแถว ตรวจจำนวนแถวก่อนและหลังให้ตรงกัน และห้ามสร้างข้อมูลที่ไม่มีในไฟล์

โจทย์ 3 · AI PRESENTATION

เล่าเรื่อง “บ้านทรายทอง” ใน 3 สไลด์

ใช้ภาพอ้างอิง ข้อมูลตัวละคร และตัวเลขจริงสมมุติ สร้าง deck ที่สั้นแต่เล่าเรื่องครบ

คำสั่งโจทย์
  1. สร้าง PowerPoint 3 สไลด์ โดยใช้ภาพไกด์ด้านล่างเป็นแนวทางการจัดวาง ไม่ต้องทำเหมือนทุกจุด
  2. สไลด์ 1: รูปรวมครอบครัวบ้านทรายทอง พร้อม caption สั้น ๆ
  3. สไลด์ 2: ตารางข้อมูลตัวละคร (ชื่อตัวละคร และผู้รับบทนำ) จากไฟล์ข้อมูล
  4. สไลด์ 3: กราฟเส้นจำนวนผู้เข้าชม พร้อม KPI รายได้ ต้นทุน และกำไรในหน้าเดียว

โจทย์ 4 · AI GAME CODING

สร้างเกมเลี้ยงปลา รับคูปองส่วนลด

ทำเกมให้ลูกค้ากดให้อาหารปลา เติบโตผ่าน 3 ระดับ และปลดล็อกคูปองเมื่อปลาโตเต็มที่

คำสั่งโจทย์
  1. สร้างเกมเว็บแบบเล่นได้จริงใน HTML ไฟล์เดียว เปิดในเบราว์เซอร์ได้ทันที
  2. มีภาพปลา 3 ระดับ: เริ่มต้น → กำลังโต → โตเต็มที่ และปุ่มให้อาหาร
  3. แสดงสถานะระดับปลา/จำนวนครั้งที่ให้อาหาร และเมื่อถึงระดับ 3 ให้แสดงคูปองส่วนลด
  4. ทดสอบปุ่ม การเปลี่ยนภาพ และข้อความคูปองก่อนส่ง ห้ามเพิ่มระบบ backend

โจทย์ 5 · BUSINESS DOCUMENTS

สร้างใบขอเบิกค่าใช้จ่ายบริษัท

ออกแบบเอกสาร Word ใหม่จาก brand kit ของบริษัทสมมุติ ให้ดูเป็นเอกสารที่ใช้ได้จริงตั้งแต่หัวถึงท้ายกระดาษ

คำสั่งโจทย์
  1. ใช้ข้อมูลจาก company profile และโลโก้บริษัทสมมุติ สร้างเอกสาร Microsoft Word ใหม่ ห้ามกรอกลงแม่แบบสำเร็จรูป
  2. ต้องมีหัวกระดาษพร้อมชื่อบริษัทและโลโก้ ชื่อเอกสาร ช่องข้อมูลผู้เบิก/แผนก/วันที่/เลขที่เอกสาร
  3. สร้างตารางรายการค่าใช้จ่ายอย่างน้อย 4 แถว พร้อมยอดรวมและช่องลงชื่อผู้เบิก ผู้ตรวจสอบ และผู้อนุมัติ
  4. ใส่ท้ายกระดาษตามข้อมูลบริษัท และแทนค่าทุก `[ข้อความ]` ใน Prompt ให้เรียบร้อยก่อนส่ง
